# Tìm Dataset Có Nhiều Ảnh

## Cách tìm dataset lớn trên Roboflow

### Cách 1: Filter theo số lượng ảnh

1. **Trên trang search results:**
   - Tìm filter **"Image Count"** (bên dưới search bar)
   - Click vào dropdown
   - Chọn **"5000+"** hoặc **"10000+"**
   - Kết quả sẽ chỉ hiển thị dataset có nhiều ảnh

### Cách 2: Sort theo số lượng ảnh

1. Tìm nút **"Sort"** hoặc **"Order by"**
2. Chọn **"Most Images"** hoặc **"Largest"**
3. Dataset có nhiều ảnh nhất sẽ hiện đầu tiên

### Cách 3: Scroll xuống

- Dataset "by GaCha" có **9161 images** (nhiều nhất)
- Có thể scroll xuống để tìm
- Hoặc search lại với filter

### Cách 4: Search với keywords khác

Thử search:
- "waste detection" (thay vì "waste classification")
- "trash detection"
- "recyclable waste"
- "garbage classification"

## Dataset lớn phổ biến

### Dataset có 9000+ images:
- **by GaCha** - 9161 images (nhiều nhất)
- Có model sẵn
- Nhiều classes

### Dataset có 4000-5000 images:
- **by Masks** - 4366 images (đang xem)
- **by bottle** - 3353 images
- **by deepu** - 2201 images

## Khuyến nghị

### Option 1: Tìm dataset "by GaCha" (9161 images)

1. **Scroll xuống** trong kết quả search
2. Hoặc **filter "Image Count: 5000+"**
3. Tìm dataset có **9161 images**

### Option 2: Combine nhiều dataset

Nếu không tìm được dataset lớn:
1. Download dataset **by Masks** (4366 images)
2. Download thêm dataset khác (2000+ images)
3. **Merge lại** thành dataset lớn hơn

### Option 3: Sử dụng Kaggle

Kaggle có dataset lớn:
- **TrashNet** - có thể download và convert
- Search "waste classification" trên Kaggle
- Nhiều dataset lớn hơn 10000 images

## Quick Actions

### Trên Roboflow ngay bây giờ:

1. **Click vào filter "Image Count"**
2. **Chọn "5000+" hoặc "10000+"**
3. **Xem kết quả** - dataset lớn sẽ hiện ra
4. **Chọn dataset có nhiều ảnh nhất**

### Hoặc:

1. **Scroll xuống** trong kết quả hiện tại
2. **Tìm dataset "by GaCha"** (9161 images)
3. **Click vào** để xem chi tiết

## Lưu ý

- Dataset lớn hơn = train tốt hơn
- Nhưng cần đảm bảo có đủ classes
- Kiểm tra format (YOLO) trước khi download
